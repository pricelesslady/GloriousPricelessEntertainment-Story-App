Glorious Priceless Entertainment (GPE)

Entertainment with Purpose. Stories with Impact.

Glorious Priceless Entertainment (GPE) is a web-based entertainment platform that enables readers to discover, read, and engage with stories in an interactive environment.

Built as an independent full-stack development project, GPE combines a reader-focused interface with backend services and a separate content management system for publishing stories.

🔗 Live Application: https://glorious-priceless-entertainment-st.vercel.app

📦 Repository: https://github.com/pricelesslady/GloriousPricelessEntertainment-Story-App

GPE was developed to create an accessible and engaging reading experience where users can explore stories, customise their reading environment, and participate through comments.

The platform is live and has attracted more than 100 readers, based on the project's reported readership.

The GPE ecosystem includes a reader-facing application and a separate content management system (CMS) used to manage and publish story content.

Key Features

- Story Discovery: Browse a library of available stories.
- Interactive Reading: Open and read published stories.
- Reader Engagement: Add comments to stories.
- Progressive Web App (PWA): Install the web application on supported devices.
- Reading Customisation: Change the reading theme, font family, and font size.
- Content Management System: Manage story titles and upload story content through a separate administrative application.
- Responsive User Interface: Designed to provide an accessible experience across supported screen sizes.

Application Architecture

GPE consists of two main applications:

1. Reader Application: Provides story discovery, reading, comments, and reading customisation.
2. Content Management System: Provides an administrative interface for managing and publishing story content.

The reader application uses React and Tailwind CSS on the frontend, with Node.js and Express.js powering backend functionality and MongoDB providing data storage.
Getting Started

To run this project locally, you will need Node.js, npm, and access to a configured MongoDB database.

Installation

1. Clone the repository:
   
   git clone https://github.com/pricelesslady/GloriousPricelessEntertainment-Story-App.git

2. Navigate into the project directory:
   
   cd GloriousPricelessEntertainment-Story-App

3. Install dependencies using the package manager and commands appropriate to this repository.

4. Configure the required environment variables using the project's environment-variable documentation. Never commit secret keys, database credentials, or private tokens.

5. Start the application using the development command defined in the project's "package.json".
